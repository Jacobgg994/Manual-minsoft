# Manual Minsoft Thailand

A web-based manual application for Minsoft Thailand, featuring a tabbed interface, search functionality, and a professional theme.

## 🚀 Tech Stack

- **Framework:** [React](https://reactjs.org/) (TypeScript)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Styling:** Vanilla CSS

## ✨ Features

- **Program Selection:** Sidebar navigation for different programs (Maxcare, MaxCloudPhone, MaxData).
- **Functional Tabs:** Categorized content within each program.
- **Search:** Real-time search across all categories within a program.
- **Responsive Design:** Professional theme with Purple (#6a1b9a) and Red (#d32f2f).

## 🛠️ Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Jacobgg994/Manual-minsoft.git
   ```
2. Navigate to the project directory:
   ```bash
   cd web-manual
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Development

Start the development server:
```bash
npm run dev
```

### Build

Build for production:
```bash
npm run build
```

## 📂 Project Structure

- `src/data/manualData.ts`: Contains the manual content and data structure.
- `src/index.css`: Global styles and theme variables.
- `public/images/`: Stores all images used in the manual.
